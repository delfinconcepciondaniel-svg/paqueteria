# Sistema RutaExpress

Sistema de información para la recepción, transporte, seguimiento y entrega de paquetes.

## Estructura del sistema

El proyecto contempla la gestión de remitentes, destinatarios, paquetes, envíos, sucursales, rutas, repartidores, vehículos, pagos, incidencias, entregas, usuarios y comprobantes.

### Módulos principales
- Gestión de usuarios y roles
- Gestión de remitentes y destinatarios
- Registro y gestión de paquetes
- Gestión de envíos
- Cálculo y registro de tarifas y pagos
- Clasificación y despacho
- Gestión de rutas y repartidores
- Seguimiento de envíos
- Gestión de entregas e incidencias
- Generación de comprobantes y reportes

## Actores
- Remitente
- Operador de Agencia
- Clasificador
- Repartidor
- Administrador
