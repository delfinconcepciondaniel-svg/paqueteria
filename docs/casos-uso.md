# Casos de uso — RutaExpress

Actores: Remitente, Operador de Agencia, Clasificador, Repartidor y Administrador.

Funciones principales: registrar envío, consultar tarifa y seguimiento, registrar paquete, registrar pagos, generar comprobantes, clasificar paquetes, asignar rutas, consultar rutas, actualizar estados, registrar entregas/incidencias, gestionar usuarios y generar reportes.
